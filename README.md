# niyyah-config

Публичные настройки приложения Niyyah, которые меняются без обновления в сторах.
Приложение читает их отсюда: https://kulmanovzhanibek.github.io/niyyah-config/ramadan.json

## ramadan.json — даты Рамадана

Без записи для страны приложение считает по таблице Умм аль-Кура и пишет «≈».

- `groups` — какие страны в какой группе. `east` — местное наблюдение/расчёт
  (Центральная Азия, Турция, Южная и Юго-Восточная Азия, Египет); `west` — Саудия
  и те, кто идёт за ней (Залив, Европа, Америка). Коды стран — ISO, две заглавные буквы.
- `ramadan` → год по хиджре (`"1448"`) → группа (`east` / `west`) или страна (`KZ`):
  - `start` — первый день поста, `ГГГГ-ММ-ДД`;
  - `days` — 29 или 30, когда объявлен Ид (до того — по таблице);
  - `confirmed: true` — дата объявлена официально: приложение уберёт «≈».
- Запись страны важнее записи её группы.

Пример: Казахстан объявил 9 февраля, 30 дней, вся остальная группа «Восток» — 8-го:

```json
"1448": {
  "east": { "start": "2027-02-08", "confirmed": true },
  "KZ":   { "start": "2027-02-09", "days": 30, "confirmed": true }
}
```

Приложение перечитывает файл не чаще раза в 6 часов, когда его открывают; GitHub Pages
отдаёт новую версию через минуту-две после коммита. Сломанный JSON приложение
игнорирует и остаётся на прошлой версии — но проверяй его перед коммитом
(`python3 -m json.tool ramadan.json`).
